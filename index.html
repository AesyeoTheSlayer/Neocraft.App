The project

Minecraft, rewritten from scratch.

NeoCraft is a full 1:1 rewrite of Minecraft in Rust, compiled to WebAssembly for a smooth, low-lag browser experience. It will recreate every client release from Alpha 1.1.2_01 through Beta 1.8.1.

01

Rust engine

Its own codebase—not a Java wrapper.

02

Browser runtime

Compiled to WebAssembly.

03

Every classic release

Each target keeps its original mechanics and feel.

Minecraft: Java Edition ownership required

Every listed release requires signing in with a Microsoft account that owns Minecraft: Java Edition.
