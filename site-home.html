The project

A Rust-based Minecraft client for the browser.

ZephyrCraft is an independent client built with Rust and WebAssembly. Development currently focuses on support for selected historical Minecraft: Java Edition versions, beginning with Alpha 1.1.2_01.

01

Rust-based client

Developed as an independent client implementation.

02

Browser runtime

Built with WebAssembly for modern browsers.

03

Version targets

Support is planned around specific historical Java Edition versions.

Minecraft: Java Edition ownership required

The test client requires legally obtained local Alpha resources. ZephyrCraft does not provide Minecraft game files.
