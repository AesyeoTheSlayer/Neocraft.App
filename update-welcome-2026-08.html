Welcome to the ZephyrCraft development log

Originally published under the NeoCraft name. This is the first ZephyrCraft development update. Here’s what the project is, where development stands, and what will be shared here going forward.

What ZephyrCraft is

ZephyrCraft is an independent Rust-based Minecraft client designed for modern web browsers with WebAssembly. It is developed as its own client implementation and does not place or redistribute the original Java client inside a webpage.

What is being built now

The current development target is compatibility with Alpha 1.1.2_01. Additional historical Java Edition versions are listed as non-final targets on the roadmap.

There is no public build or announced release date yet. Updates will be posted when there is meaningful progress to share instead of filling the page with invented deadlines or percentages.

What future updates will cover

  • Major engine and gameplay progress
  • Technical milestones in the Rust and WebAssembly client
  • Public build and release announcements
  • Important changes to the project roadmap

A reminder about the roadmap

The current version list is a direction, not a permanent promise. Included versions, their order, release plans, and account requirements can change at any time.

Thanks for following ZephyrCraft this early. The next post will arrive when there is real development progress worth showing.
