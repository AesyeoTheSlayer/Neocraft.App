Welcome to the NeoCraft development log

This is the first official NeoCraft update. Here’s what the project is, where development stands, and what will be shared here going forward.

What NeoCraft is

NeoCraft is a full 1:1 rewrite of Minecraft in Rust, compiled to WebAssembly for a smooth, low-lag browser experience. It is its own codebase—not a Java wrapper running inside a webpage.

What is being built now

The current development target is Alpha 1.1.2_01. The goal is to recreate its original mechanics and feel faithfully before moving through the later versions on the roadmap.

There is no public build or announced release date yet. Updates will be posted when there is meaningful progress to share instead of filling the page with invented deadlines or percentages.

What future updates will cover

  • Major engine and gameplay progress
  • Technical milestones in the Rust and WebAssembly rewrite
  • Public build and release announcements
  • Important changes to the project roadmap

A reminder about the roadmap

The current version list is a direction, not a permanent promise. Included versions, their order, release plans, and account requirements can change at any time.

Thanks for following NeoCraft this early. The next post will arrive when there is real development progress worth showing.
