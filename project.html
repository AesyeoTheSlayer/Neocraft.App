The project

What is NeoCraft?

NeoCraft is an independent attempt to faithfully rebuild classic Minecraft clients in Rust and run them directly in modern web browsers through WebAssembly.

A rewrite, not a wrapper

NeoCraft is being written as its own Rust codebase. It does not place the original Java client inside a webpage. Game systems, rendering, input, world behavior, and version-specific mechanics must be recreated for the browser-focused engine.

Version accuracy

Each target is treated as its own historical release with the mechanics and feel associated with that version.

Why rebuild the classic versions?

Minecraft changed rapidly during Alpha and Beta. Mechanics, terrain, interfaces, bugs, balance, and the general feel of the game shifted between releases. NeoCraft’s roadmap preserves those versions as distinct targets instead of blending the entire era into one approximation.

The current target is Alpha 1.1.2_01. The public roadmap then moves through the listed Alpha and Beta client releases in order, with Beta 1.8.1 currently being the latest listed target. Later versions are still being considered.

Ownership and authentication

Every listed Minecraft release is planned to require signing in with a Microsoft account that owns Minecraft: Java Edition. NeoCraft is not intended to replace purchasing the original game.

Current status

NeoCraft is still in development. There is no public build and no announced release date. Development posts will focus on concrete progress rather than fictional schedules or completion percentages.

A roadmap, not a promise

The version list represents the current direction of the project. Included versions, their order, release plans, technical decisions, and account requirements can change at any time as development continues.

Unofficial project: NeoCraft is independent and is not affiliated with, endorsed by, or sponsored by Mojang Studios or Microsoft.
