The project

What is NeoCraft?

NeoCraft is an independent Rust-based Minecraft client designed to run in modern web browsers through WebAssembly.

An independent client implementation

NeoCraft is developed as its own Rust and WebAssembly client. It does not place or redistribute the original Java client inside a webpage. Its browser runtime, rendering, input, and version-support systems are developed independently.

Version support

Development targets selected historical Java Edition versions as separate compatibility goals.

Why target historical versions?

Minecraft changed rapidly during Alpha and Beta. Mechanics, terrain, interfaces, bugs, and balance shifted between releases, so NeoCraft lists individual versions as separate compatibility targets.

The current target is Alpha 1.1.2_01. The public roadmap lists additional Alpha and Beta versions under consideration, with Beta 1.8.1 currently being the latest listed target.

Ownership and local resources

Using the test client requires owning Minecraft: Java Edition and supplying compatible Alpha resources locally. NeoCraft does not provide Minecraft game files and will never ask for a Microsoft password or authentication code.

Current status

The Alpha 1.1.2_01 client is playable and has entered public testing. The focus is now longer real-world play sessions, browser compatibility, low-end-device performance, unusual gameplay behavior, resource loading, save reliability, and final setup polish. There is still no announced finished-release date.

A roadmap, not a promise

The version list represents the current direction of the project. Included versions, their order, release plans, technical decisions, and account requirements can change at any time as development continues.

Not an official Minecraft product. NeoCraft is independently developed and is not approved by, associated with, endorsed by, or sponsored by Mojang Studios or Microsoft.
